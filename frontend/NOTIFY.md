## 说明
这是基于上游 v0.55.2 的个人维护版本。上游已于 2025 年停止维护，云端接口（SubtitleBest）也已下线。

## 本版改动
- 移除已失效的 a4k、SubtitleBest 字幕源，以及依赖它们的界面；
- 修复启动时卡在字幕源检查、Web UI 迟迟打不开的问题；
- 修复重启守护进程后任务并发、互相删除临时字幕的问题；
- 修复下载任务结束时偶发 panic、任务一直“排队中”反复重试的问题；
- 修复 assrt 接口格式变化导致的崩溃和解析失败；
- “启动时扫描”设置恢复生效；
- “媒体库设置”支持选择 Emby 或 Jellyfin，下载后按目录通知刷新，可填写路径映射；
- “进阶配置”新增字幕挑选优先级：优先匹配视频版本、语言偏好、站点顺序；
- 总览页显示今日下载数、任务队列、下次扫描时间，以及字幕源、媒体服务器、TMDB 的连接状态。

## 可用字幕源
迅雷、射手，以及填写了 Token 的 ASSRT。

## 建议
- 保留 TMDB API Key：中文片名只能从 TMDB 获取；
- 媒体库需要经过刮削，电影目录里最好有带 IMDB ID 的 nfo 文件。
