## 说明
这是基于上游 v0.55.2 的个人维护版本。上游已于 2025 年停止维护，云端接口也已下线。

## 本版改动
- 移除已失效的 a4k、SubtitleBest 字幕源；
- 修复启动时卡在字幕源检查、Web UI 迟迟打不开的问题；
- “启动时扫描”设置恢复生效；
- 移除已失效的远程/本地 Chrome 设置；
- “媒体库设置”支持选择 Emby 或 Jellyfin；
- 下载完字幕后按目录通知 Emby / Jellyfin 刷新，MoviePilot 等通过 API 添加的任务也会刷新（路径不同时在“媒体库设置”里填路径映射）；
- “进阶配置”新增字幕挑选优先级：优先匹配视频版本、语言偏好（双语/简体/繁体）、站点顺序；
- 总览页显示今日下载数、任务队列、下次扫描时间，以及字幕源、媒体服务器、TMDB 的连接状态；
- 没有 TMDB API Key 时改用影片目录里 nfo 的中文名和原名搜索；
- 扫描时缓存字幕语言判断，大媒体库扫描更快；下载缓存按设置的期限自动清理；
- 失败的任务会逐步降低优先级，不再一直按原优先级重试；
- 首次扫描大媒体库时入队更快，网页和接口启用 gzip 压缩；
- 库页面“字幕搜索”新增“程序搜索”，可以列出各字幕源的全部候选字幕，预览后手动挑选；
- “字幕已满意，不再自动更换”锁定后，插队任务、MoviePilot 和 Jellyfin Webhook 都不会再替换字幕；
- 下载队列可以筛选失败任务并一键重试；新增“下载历史”页面和统计；
- 新增“通知”设置（Webhook / Telegram / Bark），以及 Jellyfin 入库 Webhook；
- 登录密码改为哈希保存（回退旧版本前请先备份配置）；连续登录失败会暂时锁定；登录 30 天不用会过期。

## 可用字幕源
迅雷、射手，以及填写了 Token 的 ASSRT。

## 建议
- 建议填写 TMDB API Key：没有时只能用 nfo 里的片名，片名不全时会搜不到；
- 媒体库需要经过刮削，电影目录里最好有带 IMDB ID 的 nfo 文件。
